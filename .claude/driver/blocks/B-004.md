# B-004 Mod do diagrama vivo

## Spec

Implementar o mod do diagrama vivo conforme ADR-011: `src/shared` sem dependências, painel ao lado do chat (SVG vertical no Desktop e VS Code, quadro de cartões no mobile, linhas no terminal), tools `mcp__driver__*`, comando `/driver`, hooks `agent.spawn`, `SubagentStop` e guard `tool.call`, canal de aprovação por origem do usuário com ticket.

## Acceptance criteria

- vitest, `claude plugin test`, typecheck e `claude plugin validate` limpos.
- Painel legível no Desktop, confirmado visualmente pelo Diogo.
- `/driver approve route` funciona pelo composer ou botão do painel; recusado quando vem do modelo.

## Notes

Três renderizações rejeitadas antes do SVG vertical dimensionado em pixels (ver ADR-011, consequências). Revisão adversarial em `docs/research/06-review-mod.md`. Entregue no commit `77a61a1`; aprovação visual em 2026-10-29.

## Handoff

Painel em uso (dogfooding neste repositório). Pendência relacionada: PER-619, falso positivo do guard em heredocs, corrigida em seguida com revisão própria.
